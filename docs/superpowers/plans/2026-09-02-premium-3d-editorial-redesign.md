# Blumebyte Premium 3D Editorial Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Transform the existing Blumebyte homepage into the approved Premium 3D Editorial experience while preserving every route, accessible HTML content, contact action, product URL, and graceful non-WebGL experience.

**Architecture:** Keep TanStack React Start, React 19, TypeScript, Vite and Tailwind CSS 4. Add Three.js through React Three Fiber and Drei behind isolated lazy-loaded presentation components; capability/reduced-motion helpers choose between live WebGL and static CSS/HTML fallbacks. Keep essential copy, navigation and CTAs outside canvas; the homepage owns scene composition while small focused components own individual visual systems.

**Tech Stack:** TanStack React Start, React 19.2, TypeScript 5.8, Vite 8, Tailwind CSS 4, Bun tests, `three`, `@react-three/fiber`, `@react-three/drei`, existing Radix/shadcn primitives, Vercel.

**Spec:** `docs/superpowers/specs/2026-09-02-premium-3d-editorial-redesign-design.md`

## Global Constraints

- Preserve TanStack React Start, React 19, TypeScript, Vite, Tailwind CSS 4, Radix/shadcn-style UI primitives and Vercel deployment.
- Do not migrate frameworks.
- Palette remains exactly black `#000000`, light grey `#F1F1F1`, white `#FFFFFF`, gold `#7C5A1A`; gold is an accent, not a dominant surface.
- Target balance: approximately 65% clean premium editorial, 25% interactive 3D, 10% experimental glass/shader effects.
- Essential headings, descriptions, navigation and CTAs remain semantic HTML, never canvas-only content.
- No scroll hijacking, aggressive orbit controls, fabricated product screenshots, fabricated metrics, awards or testimonials.
- Lazy-load major WebGL code, cap DPR, keep geometry procedural/lightweight, reduce rendering offscreen, and provide static fallback when WebGL is unavailable.
- Respect `prefers-reduced-motion`: no scroll-linked camera movement, continuous rotation or animated shader requirement; all content is immediately available.
- Preserve product URLs exactly, including Ghost Tears testing URL `https://play.google.com/apps/testing/com.blumebyte.spacebob`.
- Preserve contact email `blumebyte@gmail.com`, subject `Enquiry`, and WhatsApp `+233256122555`.
- Preserve all existing routes, cookie consent, legal pages and mobile navigation.
- Do not add `shadergradient` in the first dependency pass. Build the approved restrained shader field with Three/R3F so the project has one 3D runtime; add another package only if a verified visual gap remains.

export type VisualCapability = {
